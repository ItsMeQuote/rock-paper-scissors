# Камень, ножницы, бумага

Небольшая игра «Камень, ножницы, бумага» на Python. Проект создан как учебный проект для практики Python и Git.

## Версии

История проекта разделена на версии с помощью Git-тегов:

* **v1.0.0** — первая консольная версия игры.
* **v2.0.0** — улучшенная консольная версия.
* **v3.0.0** — версия с графическим интерфейсом на CustomTkinter.

## Текущая версия

В репозитории находятся исходные файлы проекта:

* `rock_paper_scissors.py` — консольная версия игры.
* `rock_paper_scissors_gui.py` — версия с графическим интерфейсом.

Готовая Windows-версия GUI доступна в разделе **Releases**.

## Установка

Для запуска GUI-версии из исходного кода требуется Python и библиотека CustomTkinter:

```bash
pip install customtkinter
```

## Запуск

Консольная версия:

```bash
python rock_paper_scissors.py
```

GUI-версия:

```bash
python rock_paper_scissors_gui.py
```

## Готовая версия для Windows

Если не хотите устанавливать Python и запускать исходный код, скачайте готовую `.exe`-версию из **[Releases](https://github.com/ItsMeQuote/rock-paper-scissors/releases/tag/v3.0.0)**

* Python
